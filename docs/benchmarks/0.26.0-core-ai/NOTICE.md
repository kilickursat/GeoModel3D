DOI [10.1016/j.petrol.2020.107933](https://doi.org/10.1016/j.petrol.2020.107933).

GeoModel3D selected forty already cropped test images using a fixed seed. The cached source JPEG bytes are unchanged. Derived benchmark PNGs are adaptations prepared for this pilot; the benchmark protocol records the transformations. Source filenames, published class labels and source hashes appear in `dataset-manifest.json`. A displayed source class is a published reference label, not a new geologist's review or a verified prediction by GeoModel3D.
