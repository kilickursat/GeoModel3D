# GeoModel3D 0.26.0: Qwen device evaluation

This milestone prepares the larger Qwen study and a usable physical-device workflow. It does not promote Qwen into the application model selector or claim geologist-validated descriptions.

## Implementation

- Forty new reproducibly selected public core/non-core patches, immutable source and PNG hashes, explicit attribution and a separate CC BY-SA licence. Filename grouping limits repetition but does not establish borehole identity.
- A separate hosted page for single-case, five-case or forty-case local Qwen runs. Users explicitly accept the model download. Quality (128 tokens) and compatibility (32 tokens) modes stay distinct; all cases run sequentially in one worker/session.
- A pinned model, configuration, tokenizer URL template, processor and prompt. Input hashes are checked before model loading and inside the worker. Outputs are bound to the selected image/protocol and rendered as text.
- Cancellation, visibility interruption and a thirty-minute total case deadline, including image fetch. Completed, failed/timed-out, interrupted and unstarted records remain separate. Local report recovery never resumes inference automatically.
- Source-only image inspection and a blank human reference/grading sheet. No reviewer, qualification, quality score or physical-device status is fabricated. Reports include source/protocol hashes, original browser context, loading/first-token/generation/full-case timings and explicit unknown GPU memory.
- Dedicated model-cache/report storage. The page has no path into project acceptance, logs, laboratory properties or RQD. Two build passes preserve the main application's standalone bundle.

## Evaluation boundaries

The [frozen protocol and evidence](../benchmarks/0.26.0-core-ai/README.md) keep CPU diagnostics, actual software-WebGPU execution, mocked UI tests and physical-device quality separate. The local WebGPU plan selects only case-11, quality mode (128 tokens), before viewing or inference, with a thirty-minute ceiling; the remaining 39 browser cases are unrun on this environment. Human review, independently mapped boreholes and physical iPhone Safari remain required external evidence.

## Validation

TypeScript, the main/benchmark/standalone builds, all **643 unit tests in 52 files**, and **69 Playwright tests** pass. The twelve new benchmark tests use synthetic inference to check consent, exact input binding, sequential execution, mode separation, cancellation/timeouts, recovery, exports, cache isolation and mobile controls; they do not measure model quality. Source/input integrity checks pass for all forty cases.

An initial full UI run during concurrent CPU/GPU work and source writes was interrupted after four timeouts. The complete rerun after source freeze and CPU completion passed with unchanged test timeouts, including those four scenarios. A separate sandbox startup failure occurred before tests and was resolved by granting the local server network permission. These attempts are retained in the [validation record](0.26.0-validation.json).
