# GeoModel3D 0.27.0: desktop Qwen evaluation

The Qwen evaluation milestone now prioritizes a desktop or laptop hardware GPU. Chrome is preferred; Edge remains a candidate to validate on each named configuration. iPhone AI support is optional and no longer a prerequisite for the desktop milestone. Existing mobile modelling and manual core-photo workflows remain available independently.

## Scope

- Add a new desktop evaluation plan that references the unchanged forty-image inference protocol, model/runtime configuration, prompt, input hashes and visual rubric. Preserve historical protocols and evidence.
- Let operators select a primary desktop target or an exploratory device target. Record the target and new plan identity only for newly started runs; keep legacy runs unassigned.
- Summarize technical outcomes per run, keeping cold/warm sessions, compatibility/quality modes, hardware/software/unknown adapters and missing measurements separate. Require at least thirty valid warm observations for each p95 metric and use nearest rank.
- Keep all attempt outcomes and original metadata. No target selection, user agent or adapter label establishes physical-device verification. Summaries never grant overall approval, human quality or geological accuracy.
- Document a Chrome workflow: hardware acceleration, machine/OS/GPU/browser record, one case-01 compatibility check, then a separate complete forty-case quality run with prior image-only human references and later masked grading.

## Remaining evidence

The [desktop study instructions and frozen plan](../benchmarks/0.27.0-desktop-ai/README.md) make the evidence boundaries explicit. A local capability probe found no usable hardware WebGPU adapter in this managed environment; no hardware inference or new quality result was produced. Qualified human review, authoritative case-level borehole mapping and GPU/process memory suitability remain unassessed. CPU completion and software rendering cannot substitute for desktop hardware performance.

The desktop plan is frozen as `qwen-desktop-1`, SHA256 `8c5ec24878ff5efd8ac16c2f45fc10e75852614dc485bfe3b1ae4af43a9449a3`. Only the device requirement changes for the new plan. The earlier study remains unchanged and Qwen stays outside the normal application model selector pending adequate evidence.

The full browser suite used ordinary timeouts and no retries. The [validation record](0.27.0-validation.json) retains logs, checksums and the corrected development-test assertion.
