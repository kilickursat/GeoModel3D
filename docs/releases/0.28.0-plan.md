# GeoModel3D 0.28.0: depth-linked core logs

This milestone makes registered core photographs easier to inspect while desktop Qwen evaluation continues independently. A selected run gains a shared depth axis for photo annotations, unrepresented or reviewed missing-core spans, and the current borehole log. Selecting an interval highlights its exact source rectangle and corresponding original piece form.

## Scope

- Derive the view from existing run annotations and current log intervals without changing the project schema, generating observations or running a model.
- Sort rows by depth, preserve right-to-left registration, and retain leading, interior and trailing gaps. Registered rows without piece annotations remain distinct from absent photo coverage.
- Split comparison intervals at both photo and log boundaries. Preserve original piece depths and source identifiers so a comparison boundary is never presented as a new fracture.
- Compare exact, known unit IDs where both tracks are present. Missing units, missing coverage and overlapping log intervals remain explicit unknowns; no interpretation is designated as ground truth.
- Select through the chart or a keyboard-accessible interval selector. Maintain the depth window across source selection and provide an explicit limit for dense charts rather than silently omitting data.
- Export the full run to an interval CSV with source bounds, registration/review state and current-log metadata. Navigation and export do not invoke acceptance or save project changes.
- Support editable Input data, read-only model inspection, desktop/mobile layouts and the standalone file without new dependencies or external services.

## Evidence boundaries

The chart displays existing annotations rather than a photograph-derived 3-D reconstruction. The application's vertical-hole assumption and interpolation through unlogged gaps remain unchanged. Missing core is a reviewed interpretation only after the operator confirms the run's recovery accounting. Unit-label agreement is not accuracy, and this feature does not change RQD, measured laboratory properties or accepted model intervals.

The Qwen worker, prompts, pinned model/runtime, frozen image cohorts and desktop evaluation plan remain unchanged. Laptop results and qualified human quality assessment are still needed before any separate model-promotion decision.
